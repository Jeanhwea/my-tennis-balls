## 2. 各模块职责

### 应用层

**AppDelegate** (`Classes/AppDelegate.h/.cpp`)
- cocos2d-x 应用程序入口点，私有继承自 `cocos2d::Application`
- 配置 OpenGL 上下文属性（RGBA8、depth 24、stencil 8）
- 设置设计分辨率（960x540）和 `FIXED_HEIGHT` 缩放策略
- 根据屏幕尺寸选择内容缩放因子（低端/全高清/2K）
- 启动 `LevelMenuScene` 作为初始场景
- 处理前后台切换：暂停/恢复动画和音频

### 场景层

**GameScene** (`Classes/scene/GameScene.h/.cpp`)
- 以组合方式（值成员）持有 `GameController`
- `createSceneWithLevel(int)` 允许指定起始关卡
- 每帧将 `update()` 委托给 `GameController`

**LevelMenuScene** (`Classes/scene/LevelMenuScene.h/.cpp`)
- 关卡选择菜单，支持分页浏览（每页 16 个关卡，4x4 网格）
- 静态 `s_initialPage` 在场景切换间记住当前页面位置
- 按钮带入场弹性动画
- 包含上一页/下一页导航和退出按钮

### 模型层（纯数据，无渲染依赖）

**GameModel** (`Classes/model/GameModel.h/.cpp`)
- 核心游戏状态容器：关卡索引、球数、剩余目标数
- 持有 `ScoreManager` 实例
- `isCleared()` / `hasNextLevel()` / `currentLevel()` 为查询方法

**LevelData** (`Classes/model/LevelData.h/.cpp`)
- `TrayData`：描述单个托盘（位置、宽度、目标球数量），坐标使用屏幕比例 0~1
- `LevelData`：关卡 ID、名称、最大发射球数、托盘配置列表
- `getAllLevels()`：函数局部静态变量实现懒加载单例
- 使用 rapidjson 从 `Resources/levels/level_NNN.json` 加载

**ScoreManager** (`Classes/model/ScoreManager.h/.cpp`)
- 计分和连击逻辑
- `addScore(int)`：基础分 × 连击倍率，连击计数递增
- 连击超时（2 秒）自动重置
- `OnChangeCallback` 在分数/连击变化时通知控制器刷新 HUD

### 控制器层

**GameController** (`Classes/controller/GameController.h/.cpp`)
- 核心中介者，协调 Model ↔ View 通信
- `init()`：初始化竞技场、瞄准线、HUD、输入、物理
- `update()`：每帧更新模型、球体效果、收集越界物体、处理延迟移除
- 关卡生命周期：`loadLevel()` → `onLevelCleared()` / `onLevelFailed()`
- 碰撞回调分发：地板接触、球 vs 目标、球 vs 球
- `_pendingRemoval` 延迟移除模式，避免在碰撞回调中修改场景图
- `_transitioning` 标志防止关卡切换期间重复触发

**InputController** (`Classes/controller/InputController.h/.cpp`)
- 单点触摸事件监听器
- 仅在右侧发射区域（LAUNCH zone，占屏幕 20% 宽度）内响应触摸
- 拖拽偏移量转换为发射速度和方向
- `std::function` 回调：`OnLaunchCallback`、`OnDragCallback`、`OnDragEndCallback`
- 最小拖拽距离（20px）防止误触

### 视图层

**AimLineView** (`Classes/view/AimLineView.h/.cpp`)
- 拖拽瞄准线的渲染
- 虚线弹道轨迹 + 力度指示圆环 + 末端落点标记
- `init()` / `draw()` / `clear()` 生命周期

**ArenaView** (`Classes/view/ArenaView.h/.cpp`)
- 无状态命名空间函数，创建竞技场视觉效果和物理边界
- `addEdgeWalls()`：四面物理边界墙 + 墙壁微光效果
- `addFloorSensor()`：底部碰撞传感器，检测目标球/弹球出界
- `drawZones()`：背景渐变、网格线、发射区域分割线、角落装饰、暗角、准星

**BallView** (`Classes/view/BallView.h/.cpp`)
- 弹球工厂
- `spawn()`：创建球体及其 5 个视觉层（阴影、光晕、运动模糊、主球、高光、次高光），带生成动画和碰撞光环效果
- `despawn()`：禁用物理体，淡出所有视觉层，缩放销毁动画
- `updateHighlights()`：根据物理体旋转角旋转高光位置，模拟固定光源反射
- `updateMotionBlur()`：根据球速（阈值 200）显示/隐藏运动模糊层

**TrayView** (`Classes/view/TrayView.h/.cpp`)
- 托盘和目标球工厂
- `createFromLevel()` 遍历关卡配置：绘制托盘视觉（阴影、渐变主体、高光、暗线、端盖、支架、柔光）→ 创建物理体 → 在托盘上均匀生成目标球

**HUD** (`Classes/view/HUD.h/.cpp`)
- 继承自 `cocos2d::Node` 的抬头显示
- 分数/连击/球数/目标数/关卡名/提示文本标签
- `showCleared()` / `showFailed()` / `showLevelIntro()` 动画覆盖层
- 返回按钮带回调，连接 `ScoreManager::OnChangeCallback`

**ObstacleView** (`Classes/view/ObstacleView.h/.cpp`)
- 随机生成长方形障碍物（位置在左侧 5%-55% 宽度、底部 10%-40% 高度范围内）
- 每个障碍物附带物理体

**VFXHelper** (`Classes/view/VFXHelper.h/.cpp`)
- 无状态视觉效果工具集
- `initParticlePool()`：预分配 DrawNode 对象池（默认 50 个）
- `spawnHitParticle()`：粒子爆发（12 颗粒子 + 2 个冲击环 + 1 个闪光 + 微振动）
- `showFloatingScore()`：漂浮 "+N" 标签，上升淡出
- `flashNode()`：短暂闪烁节点白色

**AmbientParticles** (`Classes/view/AmbientParticles.h/.cpp`)
- 背景浮动光点粒子系统
- 动态质量调节：`setQualityLevel(0~3)` 控制粒子数（0/8/15/25）
- 光点缓慢上升，带水平漂移和淡入淡出效果

## 3. 数据流

```
AppDelegate → LevelMenuScene → GameScene(GameController)
                                    │
                    GameController::init()
                    ├── ArenaView         ← 物理边界 + 视觉效果
                    ├── AimLineView       ← 瞄准线
                    ├── HUD               ← 抬头显示
                    ├── InputController    ← 触摸监听
                    └── loadLevel()
                        ├── LevelData     ← JSON 关卡缓存
                        ├── TrayView      ← 托盘 + 目标球
                        └── ObstacleView  ← 障碍物
                                    │
                    update() 每帧
                    ├── GameModel::tick()  ← 连击超时
                    ├── BallView::updateHighlights/MotionBlur
                    ├── collectOutOfBounds()
                    └── processPendingRemovals()
                                    │
                    物理碰撞回调
                    ├── 地板接触 → 移除球/目标 + 计分 + VFX
                    ├── 球 vs 目标 → 计分(连击倍率) + VFX
                    └── 球 vs 球 → 计分(半额) + VFX
                                    │
                    关卡切换
                    ├── onLevelCleared() → 延迟 → 下一关/菜单
                    └── onLevelFailed()  → 延迟 → 重试本关
```

HUD 更新反馈环路：`ScoreManager::OnChangeCallback` → `GameController::refreshHUD()` → 更新所有 HUD 标签。

## 4. 构建系统

- **CMake** 最低版本 3.10，项目名称 `my-tennis-balls`
- 集成 cocos2d-x v3 引擎（`add_subdirectory(cocos2d/cocos)`）
- `configure_file(Version.h.in → Version.h)` 版本号生成
- 多平台支持：Android（共享库）、Linux（可执行文件）、Windows（.exe + .rc）、iOS、macOS
- 链接依赖：`cocos2d` 引擎库、macOS 下 `iconv`
- macOS/iOS 使用 Xcode 生成器，Windows 使用 Visual Studio 17 2022

## 6. 架构设计模式

### MVC + 中介者模式
- **Model**：`GameModel`、`LevelData`、`ScoreManager` — 纯 C++ 数据类，无渲染依赖
- **View**：`BallView`、`TrayView`、`ArenaView` 等 — 多为无状态命名空间工厂函数
- **Controller**：`GameController` 作为中介者，持有 Model 和 View 引用

### 组合优先于继承
- `GameScene` 值成员持有 `GameController`，`GameController` 值成员持有 `GameModel`
- 视图组件多为命名空间+自由函数，仅 UI 元素继承 `cocos2d::Node`

### 回调驱动通信
- `std::function` 回调代替继承或事件总线
- `InputController` 的发射/拖拽回调、`ScoreManager` 的变更通知、`HUD` 的返回按钮

### 延迟移除模式
- `_pendingRemoval` 向量收集待移除节点，在 `update()` 中批量处理，避免碰撞回调期间修改场景图

### 数据驱动关卡设计
- 100 个 JSON 关卡文件在运行时加载，无硬编码关卡数据
- 坐标使用相对比例（0~1），分辨率无关

### 动画驱动的视觉反馈
- 生成/销毁弹性动画、连击漂浮分数、命中粒子、闪光效果均使用 cocos2d 动作系统声明式动画
