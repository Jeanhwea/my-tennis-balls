# 注释规范

## 1. 概述

本规范基于 my-tennis-balls 项目现有的注释风格整理而成，适用于项目中所有 C++ 源文件 (.h, .hpp, .cpp) 的注释编写。

---

## 2. 注释类型与格式

### 2.1 文件头注释 - `/// @file`

用于头文件顶部，描述文件的用途。

**格式:**

```cpp
/// @file <文件名>
/// <文件描述>
```

**示例:** (来自 `GameConstants.h`, `BallView.h`)

```cpp
/// @file GameConstants.h
/// 全局常量: 标签, 掩码, 物理参数, 布局比例, 计分规则。
```

```cpp
/// @file BallView.h
/// 弹球精灵的创建和移除动画。
```

---

### 2.2 类/结构体/命名空间注释 - `///`

在类和结构体定义前，或在命名空间声明后，用 `///` 说明用途。

**格式:**

```cpp
/// <类/结构体/命名空间描述>
class ClassName { ... };
```

**示例:** (来自 `GameController.h`, `GameModel.h`, `InputController.h`)

```cpp
/// 协调 Model <-> View 通信, 关卡推进和物理系统。
class GameController { ... };
```

```cpp
/// 核心游戏状态, 纯数据无渲染。
class GameModel { ... };
```

```cpp
/// 处理触摸输入, 将拖拽手势转换为发射命令。
class InputController { ... };
```

```cpp
/// 创建物理边界墙, 地板传感器和区域视觉效果。
namespace ArenaView { ... };
```

---

### 2.3 函数/方法注释 - `///`

头文件中的方法声明使用 `///` 注释说明功能。

**格式:**

```cpp
/// <功能描述>
/// @param <参数名> <参数说明>
/// @return <返回值说明>
return_type functionName(parameters);
```

**示例:** (来自 `InputController.h`, `TrayView.h`, `VFXHelper.h`)

```cpp
/// 在指定节点上注册触摸事件监听器。
void init(cocos2d::Node *target);
```

```cpp
/// 创建关卡中的所有托盘和目标球。
/// @param outTargets 输出参数, 用于存储创建的目标球节点指针
/// @return 目标球总数
int createFromLevel(cocos2d::Node *parent, const cocos2d::Size &visibleSize,
                    const LevelData &level,
                    cocos2d::Vector<cocos2d::Node *> &outTargets);
```

```cpp
/// 初始化粒子池, 预分配 DrawNode 对象以避免运行时分配开销。
/// @param parent 粒子池节点的父节点
/// @param poolSize 池大小, 默认 50
void initParticlePool(cocos2d::Node *parent, int poolSize = 50);
```

---

### 2.4 结构体字段注释 - `///<` (尾随注释)

在结构体字段定义行的末尾用 `///<` 添加说明。

**格式:**

```cpp
<类型> <字段名>;  ///< <字段说明>
```

**示例:** (来自 `LevelData.h`)

```cpp
struct TrayData {
    float x;      ///< 中心 X (屏幕宽度比例 0~1)
    float y;      ///< 中心 Y (屏幕高度比例 0~1)
    float width;  ///< 宽度 (屏幕宽度比例 0~1)
    int targets;  ///< 此托盘上的目标球数量
};

struct LevelData {
    int id;
    std::string name;
    int maxBalls;                 ///< 允许的最大发射球数
    std::vector<TrayData> trays;  ///< 托盘配置
};
```

---

### 2.5 代码段说明注释 - `//`

在 `.cpp` 文件中，用 `//` 注释说明一段代码的用途。适用于函数内部的重要逻辑块。

**格式:**

```cpp
    // <说明文字>
    // <详细说明 (如有需要)>
    code...
```

**示例:** (来自 `LevelData.cpp`, `InputController.cpp`)

```cpp
    // Check for JSON parse errors
    if (doc.HasParseError()) { ... }
```

```cpp
    // 仅在发射区域 (右侧 LAUNCH 区域) 内触摸才生效
    auto pos = touch->getLocation();
```

---

### 2.6 多行描述注释 - `///`

在函数或复杂逻辑前，用连续 `///` 行进行详细说明。

**格式:**

```cpp
    /// <第一行概述>
    /// <后续详细说明>
```

**示例:** (来自 `BallView.cpp`)

```cpp
    /// 随球旋转同步更新高光位置，模拟固定光源下球表面反射点的滑动。
    /// 核心思路: 高光是独立节点，通过旋转光源方向向量来计算球表面上的反射位置。
    if (!ball) return;
```

---

### 2.7 成组常量/变量注释 - `// --`

在常量定义或成员变量组之前，使用 `// -- <标题> --` 进行分组标记。

**格式:**

```cpp
// -- <组标题> --
constexpr int GROUP_CONSTANT_1 = ...;
constexpr int GROUP_CONSTANT_2 = ...;
```

**示例:** (来自 `GameConstants.h`)

```cpp
// -- 字体 --
constexpr const char *FONT_UI = "fonts/arial.ttf";
// -- 节点标签 --
constexpr int TAG_BALL = 100;
// -- 碰撞分类掩码 --
constexpr int CATEGORY_BALL = 0x01;
// -- 全局物理 --
constexpr float GRAVITY_Y = -980.0f;
// -- 弹球 --
constexpr float BALL_SCALE = 0.22f;
// -- 弹球光照效果 --
constexpr float BALL_SHADOW_OFFSET_Y = -8.0f;  // 阴影 Y 偏移
```

**也用于函数分组:** (来自 `GameController.h`)

```cpp
// -- 关卡 --
void loadLevel(...);

// -- 输入与物理 --
void setupInput();

// -- 球管理 --
void spawnBall(...);

// -- 碰撞 --
bool onContactBegin(...);
```

---

### 2.8 代码逻辑分段注释 - `// --`

在函数内部用 `// --` 划分逻辑段落。

**格式:**

```cpp
// -- 段落标题 --
```

**示例:** (来自 `BallView.cpp`)

```cpp
    // -- 光照系统 --
    // 高光和次高光是独立节点，不是球的子节点，从而模拟固定光源空间效果
    // 随着球旋转，高光会在球表面滑动 (updateHighlights 中计算)

    // 主高光: 球左上方白色高光 (模拟主光源照射)
    auto highlight = Sprite::create("ball.png");
```

---

### 2.9 命名空间闭合标记 - `}  // namespace`

在命名空间闭合括号后添加注释，便于阅读。

**格式:**

```cpp
}  // namespace <命名空间名>
```

**示例:** (来自 `BallView.h`, `LevelData.cpp`)

```cpp
}  // namespace BallView

#endif  // __BALL_VIEW_H__
```

```cpp
}  // namespace
```

---

### 2.10 分支/循环/条件说明 - `//`

用于在代码中说明分支条件的意图。

**格式:**

```cpp
    // <条件说明>
    if (...) {
```

**示例:** (来自 `VFXHelper.cpp`)

```cpp
    // Pool exhausted, create temporary node (will be destroyed after use)
    auto node = DrawNode::create();
```

```cpp
    // Pool exhausted, create temporary label (will be destroyed after use)
    auto label = Label::createWithTTF("", FONT_TITLE, FLOAT_SCORE_FONT);
```

---

### 2.11 关键需求/设计决策注释 - `//`

用于标注非显而易见的约束、需求或设计决策。

**格式:**

```cpp
    // <需求说明> (Requirement <版本>)
```

**示例:** (来自 `VFXHelper.cpp`)

```cpp
    // Maximum active particles cap (Requirement 2.3)
    // spawnHitParticle uses 15 nodes: 12 particles + 2 rings + 1 flash
    static constexpr int PARTICLES_PER_HIT = 15;
```

```cpp
    // Check particle count cap (Requirement 2.3)
    // Reject spawn if adding 15 particles would exceed maximum
    if (g_particlePool.initialized && ...) { return; }
```

## 3. 注释语言

项目注释使用 **中文** 书写。

## 4. 注释风格选择指南

| 场景 | 注释格式 | 位置 |
|----------|---------------|----------|
| 文件说明 | `/// @file` | .h 文件顶部 |
| 类/结构体/命名空间说明 | `///` | 定义前 |
| 函数声明说明 | `///` + `@param`/`@return` | .h 文件中 |
| 结构体字段说明 | `///<` | .h 文件中，字段末尾 |
| 函数内多行说明 | `///` | .cpp 中，代码前 |
| 函数内单行说明 | `//` | .cpp 中，代码前 |
| 逻辑段落划分 | `// --` | .h / .cpp 中 |
| 分支/循环条件说明 | `//` | .cpp 中，分支/循环前 |
| 需求/设计决策标注 | `//` | .cpp 中，相关代码前 |
| 命名空间闭合 | `} // namespace` | 命名空间关闭处 |

## 5. 注意事项

- 注释内容应与代码同步更新，过时或错误的注释比没有注释更糟。
- 避免显而易见的注释 (如 `int i; // 计数器`)，注释应说明 WHY 而非 WHAT。
    - Bad: `i++; // 自增 i` (多余)
    - Good: `i++; // 跳过已处理的任务` (说明业务含义)
- 函数声明中的 `///` 注释使用现在时、祈使语气。
- 代码中的 `//` 注释使用中文，`///` 文档注释也使用中文。
- 注掉的无用代码应直接删除。如需保留参考，应注明原因和删除时间。
